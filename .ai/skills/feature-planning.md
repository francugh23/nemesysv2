# Feature Planning

## Workflow
1. Read current project context and stable architecture.
2. Inspect existing implementation patterns and relevant skills.
3. Verify third-party APIs through authoritative MCPs.
4. Define scope, exclusions, business rules, layers, files, migrations, risks, and verification.
5. Separate future work from the smallest complete milestone.
6. End with `Awaiting approval.`

## Pitfalls
- Planning from memory without repository evidence.
- Folding deferred features into the current milestone.
- Implementing before approval for major work.
