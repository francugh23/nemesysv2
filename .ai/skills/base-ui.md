# Base UI

## Preferred Patterns
- Verify contracts against Base UI MCP, official docs, and the installed package version.
- Use Root/Trigger/Portal/Positioner/Popup composition as generated by shadcn.
- Preserve controlled/uncontrolled semantics and forward accessibility props.
- For object values, verify comparison behavior or supply explicit equality logic.

## Pitfalls
- Handwritten focus, blur, keyboard, portal, or dismissal behavior.
- Mixing Radix examples with Base UI APIs.
- Depending on object identity when options are reconstructed.
